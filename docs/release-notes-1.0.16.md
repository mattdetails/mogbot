# Mogbot 1.0.16

## What's new in 1.0.16

- **Pictures attach on LinkedIn too** - When a site ignores a pasted picture, an agent now gives it the picture the way the site's own upload takes it. Needs Mogbot for Chrome 0.1.1, which Chrome installs from the Web Store on its own.
- **Agents say "On it" first** - For a longer task an agent opens with one short line on what it's about to do, then works.
- **Extra high and Max effort** - Two higher thinking levels under Model, where the engine supports them.
- **Keep the screen on while agents work** - A setting in Settings → Agents, so Chrome can still ask for its Allow mid-task.
- **Resize a pinned page** - Drag the line under a conversation's page to give it or the chat more room.
- **Clearer approval cards** - A "Change instructions" card says how many lines it adds and removes, with the lines in its details.

## Fixed

- No more false "No progress for 3 min" while an agent waits on your card or on a helper.
- A login for a website the app doesn't know offers a browser sign-in, not an API key.
- The phone opens a card's own conversation, keeps saying an agent is working, stays awake while you dictate, and says when your Mac is too old to send it notifications.
- A Claude Code question on the phone lists its real options.
- Preview screenshots no longer say Screen Recording is denied when it's allowed; ⌘K finds every project.
- Each project tab shows when you last used it; slow thumbnails and phone screenshots no longer count as errors.
- Security hardening across approvals, the agent bridge, the preview proxy and bug reports.
