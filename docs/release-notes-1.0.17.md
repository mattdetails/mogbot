# Mogbot 1.0.17

## What's new in 1.0.17

- **Talk to an agent while it works** - A message you send mid-task goes straight into the turn: Claude Code reads it at its next step and changes course. Under your message you see when it was read.
- **Agents keep you posted** - "On it" before they start, then a short line as each step lands, so you always know it's moving.
- **Projects open on an agent's chat** - Opening a project lands on the agent that works there, or asks who should. An agent can work on several projects, one conversation and copy each.
- **One OK per post** - Approve a post's exact words (on its card or in a plan) and every click to schedule or post it on that site goes through: the clock, Confirm, Schedule. Buttons that only open a composer never ask, and pictures an agent made itself upload without a card.
- **Adding a second Claude account** - Its sign-in opens in a new window where no one is signed in, so you can add another account without signing out of the one you have.
- **Terminals follow your engine** - A project's terminals open on the engine and model chosen in Settings → Agents.
- **Folders for agents** - Group agents into folders (Website, SEO, Outreach…) from any agent's menu or by dragging; the Chief stays on top, and the phone shows the same folders.
- **Terminal tabs use all your accounts** - A project's Claude Code or Codex tab starts on the first account with room, and when one runs out it asks to continue on the next (or switches on its own, if you choose that in Settings → Accounts & usage).
- **Accounts in the menu bar** - Each account with what's left and which runs next, plus "Continue a Terminal chat" on another account.
- **The model under the message box** - Shows which model a chat runs on; click it to change.

## Fixed

- Windows: agents save again (no more missing Chief of Staff or "Access is denied (os error 5)"), and background commands no longer flash cmd windows.
- A sign-in, passcode or code step stays in the browser the agent is already working in; agents start in the browser signed in to the site.
- A plan you approved lasts an hour past its last action (8 hours at most), and covers closing issues it names.
- On the phone, a Claude Code question with "Type something" takes your own words as the answer.
- The iPhone app is on the App Store: setup links there instead of TestFlight.
- Result cards from a kept copy end on one clean footer line with Ask for changes beside Review changes.
- Hovering a row on an agent's sheet no longer hides it; long menus can be reached with the keyboard.
