# Mogbot 1.0.18

## What's new in 1.0.18

- **Your Chrome is the browser** - When an agent has your own Chrome, it uses it for every site, where you're already signed in; the agents' own browser is only for when there's no Chrome.
- **Catch up on the phone** - A card that expired or was answered on the Mac while your phone was away no longer shows as waiting.
