# Mogbot 1.0.22

## What's new in 1.0.22

- **Dictation in your language** - Dictation now hears which language you're speaking before writing it out, so Ukrainian, Serbian, Croatian and the rest come out in that language instead of as English-sounding nonsense.
- **Accounts named by who they really are** - Usage names each Claude account by the account its sign-in actually belongs to, so a re-signed account no longer shows under its old name or flags the wrong one as "Same account".
- **Usage on the phone holds still** - The phone's Usage sheet opens on the last numbers it read and keeps them until fresh ones arrive, instead of flashing empty or wrong figures.
- **Switch a terminal tab's account** - A project's Claude Code tab shows the account it runs on in its header. Pick another under "Continue this chat on" and the chat carries on there.
- **New folder in the sidebar** - A New folder button sits at the foot of the Agents sidebar, between New agent and New room.
- **Side by side** - Show the Agents chat and a project's workspace next to each other in one window, with a divider you can drag.
- **Added accounts open on your chat** - Continuing a chat on another Claude account no longer stops at Claude Code's first-run screens.
